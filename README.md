## Full site (your uploaded file + animations)

The complete website is the **uploaded HTML** enhanced with rich motions and animations.

**Because the file is large (~684 KB with embedded media), upload it manually:**

1. Download `caveman-enhanced.html` from the chat
2. In this repo click **Add file → Upload files**
3. Drop the file and **rename it to `index.html`**
4. Commit the change

Then go to **Settings → Pages** → Source: Deploy from a branch → `main` / `/ (root)` → Save.

Live URL: **https://cg-ConceptGrid.github.io/caveman-decorations/**
